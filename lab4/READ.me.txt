4. Lỗi gặp phải và cách khắc phục
- Lỗi thiếu quyền khi chạy SYN scan, UDP scan và OS detection: Khi gõ nmap -sS, nmap -sU hoặc nmap -O bằng tài khoản thường, Nmap báo lỗi yêu cầu raw socket privileges; khắc phục bằng cách thêm tiền tố sudo trước câu lệnh.
- Lỗi ping không phản hồi từ máy Windows: Máy đích Windows Server bật sẵn tường lửa chặn các gói tin ICMP Echo Request; khắc phục bằng cách vào Windows Defender Firewall with Advanced Security kích hoạt rule cho phép File and Printer Sharing (Echo Request - ICMPv4-In) hoặc bổ sung tùy chọn -Pn trong Nmap để bỏ qua bước ping.
- Lỗi lọc Grepable "No such file": Khi chạy lệnh grep "445/open" smb.txt bị báo lỗi không tìm thấy tệp do chưa hoàn thành bước quét xuất file -oG smb.txt; khắc phục bằng cách chạy lệnh tạo tệp xuất dữ liệu trước khi thực hiện pipe/grep lọc kết quả.
- Lỗi thiếu gói xsltproc khi tạo HTML: Lệnh xsltproc báo command not found; khắc phục bằng cách chạy lệnh sudo apt install xsltproc trên Kali Linux trước khi tiến hành chuyển đổi báo cáo.
